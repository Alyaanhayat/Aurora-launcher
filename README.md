# Aurora Launcher

**Aurora Launcher** is a modern, customizable Android launcher designed to bring a fresh, personal, and convenient experience to your Android device.

Built natively for Android using **Kotlin**, Aurora Launcher focuses on customization, productivity, accessibility, and a clean user experience. It is designed to give users more control over how their home screen looks, feels, and works, while keeping everyday interactions simple and intuitive.

## ✨ Features

- **Customizable Home Screen:** Personalize your home screen to match your style and preferences.
- **Custom Icon Packs:** Add and apply custom icon packs directly through Aurora Settings.
- **Gesture Controls:** Navigate your device using convenient gestures for faster access to everyday actions.
- **App Drawer:** Browse and organize your installed applications through a clean, accessible app drawer.
- **Universal Search:** Quickly find applications and access useful content without navigating through multiple screens.
- **Productivity Shelf:** Keep useful productivity tools and shortcuts within easy reach.
- **App Vault:** Hide selected applications behind password protection for an additional layer of privacy within Aurora Launcher.
- **Aurora Settings:** Access customization options and configure your launcher experience in one place.

## 🎨 Designed for Personalization

Aurora Launcher is built around the idea that a home screen should feel personal. From application icons to gestures and launcher settings, users can customize their experience according to their own preferences.

Rather than forcing everyone into the same layout, Aurora aims to provide flexibility while maintaining a consistent and polished interface.

## ⚙️ Native Android Development

Aurora Launcher is developed using Kotlin for native Android functionality. It is designed as an Android application rather than a website wrapped inside an app.

This allows Aurora to focus on Android-specific interactions, system integration, and a launcher experience that feels at home on Android devices.

## 🔒 Privacy and Convenience

Aurora includes App Vault, allowing users to hide selected applications behind a password requirement. Biometric authentication, including fingerprint unlocking, is planned for a future update.

## 🚀 Our Vision

Aurora Launcher aims to make everyday Android interactions more personal, organized, and enjoyable. With a focus on customization, useful features, and continuous improvements, Aurora is being developed to offer an alternative launcher experience for users who want more control over their devices.
